## 1. 项目目标与背景

### 目标
一个**本地优先（local-first）**的 Web 应用，把「番茄钟专注计时」「习惯打卡」「数据统计」三件事放在一个页面里，帮助用户专注、建立习惯、看见自己的积累。核心设计原则：**数据只存在用户浏览器（localStorage），不上传任何服务器、无需注册、无需联网**。

### 背景与来由
- 立项起点是一次「整体回顾 + 广泛调研 + 改进」：先对标市面最赚钱/最有用户的番茄钟应用（Forest、番茄ToDo/Focus To-Do、TickTick 等），再逐项补齐能力。
- 为了让「坚持」这件事更有温度，做过一轮**情感化设计（gamification）**调研：重点研究了竞品「椅子上有猫 / Cat On Chair」（专注时小猫上椅陪伴、完成给随机礼物、提前退出留垃圾但不羞辱）。本项目最初实现了「小猫陪伴 + 专注币奖励循环」，后经用户反馈「别重复用小猫了，换一个思路吧」，改为**「专注小园」生长型植物隐喻**（植物随专注次数长高、长叶、开花），既保留奖励经济，又避免与竞品雷同。

### 当前定位
- 纯前端单页应用（SPA），可部署为 PWA（支持「添加到主屏幕」、离线缓存）。
- 充当个人专注/习惯看板；换设备通过「数据备份」导出/导入 JSON 迁移，**无跨设备云同步**。

## 2. 技术栈与架构

### 技术栈
| 层 | 选型 |
|---|---|
| 框架 | Vue 3（`<script setup lang="ts">` 组合式 API） |
| 状态 | Pinia（`defineStore`，单 store `useAppStore`） |
| 构建 | Vite 5（`@vitejs/plugin-vue`） |
| 语言 | TypeScript（严格模式 `strict: true`），`vue-tsc` 类型检查 |
| 测试 | Vitest 4 + jsdom + `@vue/test-utils` |
| 规范 | ESLint（flat config）+ Prettier（`eslint-config-prettier`） |
| 持久化 | 浏览器 `localStorage`（全量快照，schema 版本化迁移） |
| 音频 | WebAudio 振荡器实时合成提示音（**无音频文件**） |
| PWA | `public/manifest.webmanifest` + `public/sw.js`（仅生产构建注册 Service Worker） |

### 架构总览
```
                 ┌──────────────────────────────────────────┐
   UI 组件层      │  App.vue（栅格布局 + 主题 + 习惯提醒唤起） │
   (components)   │   ├ PomodoroTimer  HabitList  TaskBoard  │
                 │   ├ StatsPanel(含8个图表) DataManager      │
                 │   ├ CompanionShop(专注小园)  ToastHost    │
                 └───────────────┬──────────────────────────┘
                                 │ 读/写
                 ┌───────────────▼──────────────────────────┐
   状态层         │  stores/useAppStore.ts (Pinia)            │
   (Pinia)       │   state/ getters/ actions                 │
                 │   $subscribe(deep) → persistence.saveState│
                 └───────────────┬──────────────────────────┘
                                 │ 载入/迁移
                 ┌───────────────▼──────────────────────────┐
   持久化层       │  stores/persistence.ts                    │
   (localStorage)│   loadState / withDefaults / saveState    │
                 │   utils/normalize.ts（字段级归一化）       │
                 └───────────────┬──────────────────────────┘
                                 │ 依赖
   ┌─────────────┬───────────────▼───────────────┬────────────────┐
   │constants/index│  composables/（useTimer等）   │ utils/（date/habit/│
   │(配置/皮肤/币) │  types/models.ts（数据契约）   │  importExport/id）│
   └─────────────┴───────────────────────────────┴────────────────┘
```
> 数据流是单向的：组件触发 store action → 状态变更 → `$subscribe` 深度订阅自动 `saveState` 到 localStorage。载入时 `loadState` 读取原始数据，`withDefaults` + `normalizeX` 补齐缺失字段并迁移旧版本。

### 关键架构约定
- **单一数据源**：`src/types/models.ts` 是全局唯一的数据契约（类型），组件/store/工具都从这里引用。
- **纯函数抽取**：计时核心逻辑在 `composables/timerLogic.ts`（不依赖 Vue/DOM，便于单测）；习惯频率/连续天数在 `utils/habit.ts`。
- **路径别名**：`@` → `src/`（见 `vite.config.ts` 与 `tsconfig.json` 的 `paths`）。
- **Schema 版本化**：`SCHEMA_VERSION = 3`（`constants/index.ts`）。`loadState` 遇到**更高版本**备份到 `CORRUPT_BACKUP_KEY` 后回退默认；老数据（无 version）交给 `withDefaults` 归一化迁移。
- **PWA 注册门槛**：`main.ts` 仅在 `import.meta.env.PROD` 下注册 Service Worker，避免干扰 dev 热更新。
- **部署约束**：`base: './'`（相对路径，适配 GitHub Pages 子路径）；构建产物输出到**仓库根 `../docs/`**（GitHub Pages 仅支持 `/` 或 `/docs` 作为源）。

## 7. 已知的遗留问题与限制

1. **代码未推送（最高优先级）**：因网络不稳定 + **曾有泄露的 GitHub PAT（已吊销）**，当前 `origin/main` 跟踪状态为 `[gone]`，所有提交仅在本机。需使用新 token/SSH 推送。
2. **无后端/无云同步**：数据仅存浏览器 localStorage。换设备只能靠「数据备份」导出/导入 JSON；不同浏览器/设备数据互不可见。
3. **通知在 iframe/预览面板被拦截**：嵌入预览环境浏览器会拦截通知权限申请，已加看门狗超时 + 「在独立窗口打开」出口，但体验仍受限。
4. **音频需用户手势解锁**：浏览器策略要求，`useSound.unlockAudio` 在首次点击/按键时恢复 `AudioContext`。
5. **构建脚本含 `rm -rf ../docs`**：会清空仓库根 `docs/`（构建产物，被 git 跟踪）。这是有意设计，但确认执行环境不会误伤其他内容；`.workbuddy/` 不在此路径，安全。
6. **习惯完成率/热力图视图固定**：习惯完成率为固定 7 天视图；热力图为固定 14 周。如需更长区间需扩展。
7. **陪伴内容偏少**：目前 `PLANT_FORMS` 4 种、`CELEBRATIONS` 3 种，扩展需同步改 `constants` 与 `Companion.vue` 上色逻辑。
8. **统计组件缺单测**：现有 54 项测试覆盖 store/utils/timer，统计子组件未覆盖，建议补充。
9. **国际化缺失**：UI 全中文，无 i18n 框架。
10. **`docs/` 为构建产物却被跟踪**：GitHub Pages 需要；每次 build 会更新哈希文件名，提交时会产生删除旧/新增新的 diff，属正常。

## 9. 环境变量与配置说明

**本项目无服务端、无 `.env`、无密钥配置**（纯静态前端）。需要了解的配置项如下：

| 类别 | 说明 |
|---|---|
| `import.meta.env.PROD` | Vite 内置。仅生产构建为 `true`，用于门控 Service Worker 注册（`src/main.ts`）。 |
| `localStorage` 键 | `focus-habit-panel:v1`（主数据）、`focus-habit-panel:corrupt-backup`（损坏/高版本备份）。定义在 `constants/index.ts`。 |
| 运行期配置（用户侧） | 全部在 UI 设置（`TimerSettings.vue` + `CompanionShop.vue`）：专注/休息时长、长休间隔、自动开始、通知/声音开关、声音类型、每日目标、主题、植物形态、庆祝、寄语等。 |
| Schema 版本 | `SCHEMA_VERSION = 3`（`constants/index.ts`）。**新增持久化字段时务必 +1 并在 `normalize`/`withDefaults` 提供迁移/默认值**，否则老用户数据会缺字段。 |
| `vite.config.ts` | `base: './'`、`build.outDir: '../docs'`、`resolve.alias['@']`、`test.environment: 'jsdom'`、`server.port 5173`。 |
| `tsconfig.json` | `paths['@/*'] → src/*`、`strict: true`、包含 `src/**/*.{ts,d.ts,vue}`。 |

> 未来若要接后端/云同步，建议新增 `.env`（并经 `vite` 注入 `import.meta.env.VITE_*`）与对应的 `composables/useSync.ts`，并注意**不要提交任何真实密钥**（参见 §7-1 泄露 PAT 教训）。
