# 文件职责清单（File-by-File）

> 与 [`项目交接文档.md`](./项目交接文档.md) §5 互补：这里按目录逐文件列出职责与「改什么找哪个文件」的速查。

## 配置 / 入口（根目录）
| 文件 | 职责 |
|---|---|
| `index.html` | Vite 入口，挂载 `#app`，加载 `/src/main.ts`，声明 PWA manifest/icon。 |
| `package.json` | 依赖与脚本：`dev/build/preview/typecheck/test/lint/format`。 |
| `vite.config.ts` | `base:'./'`、`build.outDir:'../docs'`、`@` 别名、`test.environment:'jsdom'`、`server.port:5173`。 |
| `tsconfig.json` / `tsconfig.node.json` | TS 严格模式、`paths['@/*']`、`include src`。 |
| `eslint.config.js` | ESLint flat config（忽略 `dist/ docs/ node_modules/ public/`）。 |
| `README.md` | 面向用户的功能说明。 |
| `public/manifest.webmanifest` | PWA 安装清单。 |
| `public/sw.js` | Service Worker（离线缓存）。 |
| `public/icon.svg` / `icon-maskable.svg` | 应用图标。 |

## `src/` 源码
### 入口与类型
| 文件 | 职责 |
|---|---|
| `src/main.ts` | 创建 app+pinia；`$subscribe(deep)` 自动 `saveState`；PROD 注册 SW。 |
| `src/App.vue` | 顶层栅格布局、主题切换（`document.documentElement.dark`）、唤起 `useHabitReminders`；组合各卡片组件。 |
| `src/style.css` | 全局样式 + CSS 变量（亮/暗主题）。 |
| `src/env.d.ts` | Vite 客户端类型 + `*.vue` 模块声明。 |
| `src/types/models.ts` | **数据契约**：`Habit/Session/Task/Settings/CompanionState/AppState` 等。改结构先改这里。 |

### 常量与状态
| 文件 | 职责 |
|---|---|
| `src/constants/index.ts` | `DEFAULT_SETTINGS`、`HABIT_COLORS`、`SOUND_PROFILES`、`PLANT_FORMS`、`CELEBRATIONS`、`FOCUS_GIFTS`、`SCHEMA_VERSION`、存储键；`focusCoins()`、`plantStage()`、`getForm()/getCelebration()/findCosmetic()`。 |
| `src/stores/useAppStore.ts` | **唯一 Pinia store**：state + getters + actions（习惯/任务/专注/复盘/陪伴解锁/导入）；`recordFocus` 记账+推进 `pomoCycle`+发露珠。 |
| `src/stores/persistence.ts` | `loadState`（解析+损坏/高版本备份）、`saveState`（全量写）、`withDefaults`（合并默认+归一化）。 |

### composables（无 UI 逻辑）
| 文件 | 职责 |
|---|---|
| `src/composables/useTimer.ts` | 番茄钟状态机（基于时间戳锚点），专注/休息切换、Wake Lock、标签页标题。 |
| `src/composables/timerLogic.ts` | 纯函数：`computeRemainingSeconds/isLongBreakDue/nextModeAfterFocus/cycleInfo`。 |
| `src/composables/useSound.ts` | WebAudio 提示音合成 + 音频上下文解锁。 |
| `src/composables/useNotification.ts` | 桌面通知权限申请（看门狗超时）+ 发送 + 点击置顶。 |
| `src/composables/useHabitReminders.ts` | 每分钟轮询到点且未打卡习惯，弹 toast+通知（每日每习惯一次）。 |
| `src/composables/useToast.ts` | 全局 toast 单例 `pushToast`。 |

### utils（纯工具）
| 文件 | 职责 |
|---|---|
| `src/utils/date.ts` | `todayKey/lastNDays/weekdayLabel` 等。 |
| `src/utils/habit.ts` | `isDueOn/isDueToday/streakOf/freqSummary`（频率感知连续天数）。 |
| `src/utils/importExport.ts` | `sanitize()` 导入 JSON 字段级校验+清洗。 |
| `src/utils/normalize.ts` | `defaultX/normalizeX` 补齐缺失字段（迁移/导入共用）。 |
| `src/utils/id.ts` | `uid()` 生成唯一 id。 |
