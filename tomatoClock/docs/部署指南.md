# 部署指南

本项目为纯前端静态应用，可部署到任意静态托管平台。

## 方式一：GitHub Pages（已配置）

项目已配置 `vite.config.ts` 的 `base: './'`，构建产物输出到 `docs/` 目录。

1. 推送代码到 GitHub
2. 仓库 Settings → Pages → Source 选择 `main` 分支，目录选择 `/docs`
3. 访问地址：`https://<用户名>.github.io/<仓库名>/`

当前地址：https://pythontryer.github.io/tomatoClock/

## 方式二：Gitee Pages（国内加速）

Gitee Pages 国内访问速度快，适合作为镜像。

### 步骤

1. 注册/登录 [Gitee](https://gitee.com)
2. 右上角「+」→「新建仓库」→ 选择「导入已有仓库」
3. 填入 GitHub 仓库地址：`https://github.com/pythontryer/tomatoClock.git`
4. 仓库名称建议 `tomatoClock`，设为公开
5. 导入完成后，进入仓库 → 「服务」→「Gitee Pages」
6. 部署目录：`docs`，分支：`master`（或 `main`）
7. 点击「启动」，等待部署完成
8. 访问地址：`https://<用户名>.gitee.io/tomatoclock`

### 注意事项

- Gitee 免费版 Pages 需要手动更新：每次推送后需到 Gitee 仓库点击「同步」，再到 Pages 页面点击「更新」
- Gitee Pro 版支持自动部署
- 如遇样式 404，确认部署目录选择的是 `docs` 而非根目录

## 方式三：自己的服务器（Nginx）

当前已部署到 `https://49.233.88.171/`

### 手动部署

```bash
# 1. 本地构建
cd tomatoClock
npm run build

# 2. 打包
cd ../docs
tar -czf /tmp/site.tar.gz .

# 3. 上传到服务器
scp /tmp/site.tar.gz user@server:/tmp/

# 4. 服务器上解压
ssh user@server
sudo rm -rf /var/www/tomatoclock/*
sudo tar -xzf /tmp/site.tar.gz -C /var/www/tomatoclock
sudo chown -R www-data:www-data /var/www/tomatoclock
```

### Nginx 配置参考

```nginx
server {
    listen 80;
    listen 443 ssl;
    server_name _;
    root /var/www/tomatoclock;
    index index.html;

    # SSL 证书（自签名或 Let's Encrypt）
    ssl_certificate /etc/nginx/ssl/tomatoclock.crt;
    ssl_certificate_key /etc/nginx/ssl/tomatoclock.key;

    # gzip
    gzip on;
    gzip_types text/css application/javascript image/svg+xml application/json;

    # 静态资源长期缓存
    location /assets/ {
        expires 1y;
        add_header Cache-Control 'public, immutable';
    }

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 方式四：Vercel / Netlify / Cloudflare Pages

这些平台支持 Git 推送自动部署：

1. 导入 GitHub 仓库
2. 构建命令：`npm run build`
3. 输出目录：`docs`（注意是仓库根的 `docs`，不是 `tomatoClock/docs`）
4. 由于仓库根是 `软件项目`，项目在 `tomatoClock/` 子目录，需要设置根目录为 `tomatoClock`，构建输出为 `tomatoClock/../docs` 即 `docs`

> 注意：这些平台的国内访问速度不稳定，建议作为备用。

## HTTPS 配置

桌面通知、麦克风录音等功能需要 HTTPS 环境。

- **GitHub Pages / Gitee Pages / Vercel**：默认提供 HTTPS
- **自己的服务器**：
  - 有域名：用 [Let's Encrypt](https://letsencrypt.org/) 免费证书 + certbot 自动续期
  - 无域名：用自签名证书（浏览器会提示不安全，点击「高级」→「继续访问」）
