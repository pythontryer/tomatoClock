### 回答模板

**标题/开头：**

我用番茄工作法 3 年了，试过 Forest、番茄 ToDo、滴答清单，最后自己写了一个。

**正文：**

先说结论：如果你在意隐私、不想被广告打扰、又想要一点游戏化反馈，可以试试我做的这个——[专注与习惯面板]([你的体验链接])。

它的核心特点：

1. **数据全在本地**。不需要注册，不需要登录，所有数据存在浏览器 localStorage，不上传任何服务器。换设备可以导出 JSON 备份迁移。这一点对我很重要，我不想让我的专注记录和习惯数据被第三方收集。

2. **植物成长反馈**。每完成 4 个番茄，页面里的植物就会成长一个阶段（种子→发芽→成长→绽放）。完成专注还会获得「露珠」，可以给植物浇水、在商店解锁不同形态。比单纯的数字计数更有正反馈。

3. **专注等级系统**。累计番茄数对应等级（新手→学徒→达人→专家→大师→宗师），有明确的升级进度条，长期使用有成长感。

4. **完整的统计**。不只是计时，还有周/月趋势图、专注热力图、习惯完成率、任务预估偏差。数据可视化做得比较细，能看到自己的专注规律。

5. **自定义提示音**。可以上传自己的音频，或者直接录音作为番茄结束提示音。我自己录了一段猫叫，每次结束都很治愈。

6. **PWA 可安装**。添加到主屏幕后像原生 App 一样打开，离线也能用。

技术上是 Vue3 + TypeScript 写的，开源在 GitHub，除了 Pinia 外零运行时依赖，图表都是 SVG 手绘的。

**结尾：**

链接在这里，直接打开就能用，不需要下载：[专注与习惯面板]([你的体验链接])

## 二、V2EX（极客分享风）

### 标题
`分享一个我做的番茄钟应用 —— 本地优先 + 植物成长 + 自定义提示音`

### 正文

做了一个番茄钟 + 习惯打卡 + 数据统计的 Web 应用，纯前端，数据全在 localStorage，不需要后端和注册。

**为什么又做一个番茄钟？**

- 想要一个**完全本地**的，数据不上传任何服务器
- 想要**植物成长**的游戏化反馈，但 Forest 是付费的且数据在云端
- 想要**自定义提示音**（可以上传或录音），现有工具大多不支持
- 想要**完整的数据统计**（热力图、趋势、习惯率），而不只是一个计时器

**功能清单：**

- 番茄钟：专注/短休/长休，自动长休息节奏，桌面通知，标签页倒计时
- 专注小园：每 4 个番茄植物进阶，露珠经济，商店解锁形态，专注等级系统
- 习惯打卡：连续天数，拖拽排序
- 任务绑定：番茄钟绑定任务，自动累计
- 统计：KPI 卡片、趋势图、热力图、任务分布、习惯完成率、预估偏差
- 自定义提示音：上传音频或直接录音（MediaRecorder）
- 数据备份：导出/导入 JSON，支持覆盖或合并
- PWA：可安装，离线可用
- 亮/暗主题

**技术栈：** Vue3 + TypeScript + Pinia + Vue Router + Vite，除 Pinia/Router 外零运行时依赖，图表 SVG 手绘，提示音 WebAudio 合成。93 项单元测试，CI 全绿。

**在线体验：** [你的体验链接]

**GitHub：** https://github.com/pythontryer/tomatoClock

欢迎试用和反馈，有 issue 直接提。

## 六、Product Hunt（英文）

### Title
`Focus & Habit Panel — A pomodoro timer that grows a plant as you focus`

### Tagline
`Local-first pomodoro timer with plant growth, custom sounds, and rich stats. No account, no server.`

### Description

A local-first web app that combines pomodoro timer, habit tracking, and data visualization. Every 4 pomodoros grow your plant one stage. Earn dew drops to water your plant and unlock new forms. Upload or record custom notification sounds. All data stays in your browser — no account, no server, no tracking.

**Features:**
- Pomodoro timer with focus/short/long break modes
- Plant growth system (4 stages) with dew drop economy
- Focus levels (Novice → Master → Grandmaster)
- Habit tracking with streak counts
- Task binding to pomodoro sessions
- 5 types of data charts (trend, heatmap, distribution, habit rate, estimate variance)
- Custom notification sounds (upload audio or record directly)
- Data export/import (JSON, merge or overwrite)
- PWA — installable, works offline
- Light/dark theme

**Tech:** Vue 3 + TypeScript + Pinia, zero runtime dependencies beyond state management.
